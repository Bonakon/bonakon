Какие данные мы собираем

Наше приложение использует Pinterest API исключительно для публикации пинов на нашем бизнес-аккаунте. Мы не собираем персональные данные пользователей. Единственные данные, к которым осуществляется доступ — токены авторизации нашего собственного аккаунта Pinterest, необходимые для работы с API.

Как используются данные

Токены доступа используются исключительно для автоматизации создания и публикации пинов на бизнес-аккаунте Bonakon в Pinterest. Данные не используются для рекламы, профилирования или передачи третьим лицам.

Передача третьим лицам

Мы не продаём, не передаём и не обмениваем данные с третьими лицами. Приложение взаимодействует исключительно с Pinterest API (api.pinterest.com).

Безопасность

Все API-ключи хранятся в защищённом виде и недоступны публично. Доступ ограничен членами внутренней команды.
