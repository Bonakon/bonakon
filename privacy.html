2. Какие данные мы собираем

Наше приложение использует Pinterest API v5 исключительно для автоматической публикации пинов на нашем бизнес-аккаунте Bonakon. Мы не собираем и не храним персональные данные сторонних пользователей.

Единственные данные, к которым осуществляется доступ:

  • Токены авторизации OAuth 2.0 нашего собственного Pinterest-аккаунта
  • Идентификаторы досок (boards) нашего аккаунта для публикации пинов
  • Метаданные публикуемых пинов (заголовок, описание, изображение)

3. Как используются данные

Все данные используются исключительно для следующих целей:

  • Автоматическое создание и публикация пинов на бизнес-аккаунте Bonakon
  • Планирование публикаций по расписанию
  • Чтение информации о досках для корректной публикации

Данные не используются для рекламы, профилирования пользователей или любых иных целей, кроме указанных выше.

4. Передача третьим лицам

Мы не продаём, не передаём и не обмениваем никакие данные с третьими лицами. Приложение взаимодействует исключительно с Pinterest API (api.pinterest.com) в соответствии с условиями использования Pinterest.

5. Хранение и безопасность данных

Все API-ключи и токены доступа хранятся в защищённом виде на защищённом сервере. Доступ к ним ограничен членами внутренней команды Bonakon. Токены не передаются публично и не хранятся в открытом виде.

6. Срок хранения данных

Токены доступа Pinterest действуют в соответствии с политикой Pinterest (access token — 30 дней, refresh token — 1 год) и обновляются автоматически. При прекращении использования API все токены отзываются.
